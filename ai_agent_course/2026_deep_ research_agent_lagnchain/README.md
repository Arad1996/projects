# ⚽ World Cup 2026 Deep Research Agent

This is a simple AI agent built while learning **LangChain** and **Deep Agents**.

The agent can answer questions about the 2026 FIFA World Cup, search the web for recent information, use custom tools, and chat through a Gradio interface.

## What I Used

* LangChain
* LangGraph
* Deep Agents
* OpenAI GPT-5.4 Mini
* Google Serper API
* Gradio

## Features

* Search the web for World Cup information
* Use a custom tool to look up team information
* Demonstrate Human-in-the-Loop approval for a notification tool
* Keep conversation memory with LangGraph
* Show which tools the agent uses while answering

## Try Asking

* When did Argentina win the World Cup?
* Tell me about Brazil.
* Compare Brazil and France.
* Write a short report about Brazil.

This project was built as practice with LangChain agents, tools, middleware, memory, and Gradio.
