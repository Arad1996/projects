# Basketball Multi-Agent Analysis System

Built a multi-agent AI system to analyze a basketball matchup between Hapoel Tel Aviv and Maccabi Tel Aviv.

The system uses specialized agents to evaluate team statistics, player strengths, weaknesses, and key matchups. A final analysis agent reviews all reports and generates a game prediction with supporting reasoning.

### Features

* Multi-agent architecture using OpenAI Agents SDK
* Specialized scouting agents for statistics, weaknesses, and matchups
* Parallel agent execution for faster analysis
* Automated game prediction based on agent reports
* Optional email delivery of the final analysis
